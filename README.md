# 建筑与建造师认证考试笔记本（**`construction-certs`**）

[![License: CC BY 4.0](https://img.shields.io/badge/License-CC%20BY%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by/4.0/deed.zh)

> 把「一级 / 二级建造师」的报考、备考、注册与执业，拆成可执行动作的备考笔记库。

本仓库不是教材复刻，也不是押题合集，而是一套**以"考得过、用得上"为交付目标的行动手册**：每篇按「资格 → 考试 → 注册 → 执业」全周期拆成若干板块，板块内再拆成「这是什么 → 为什么 → 怎么办 → 怎么验证 → 出错怎么办」，读完能照着做。

## README · 导览

### README_1 这是什么，与库内体例

本仓库收录建筑与建造师类考试的**备考方法笔记**，面向一级、二级建造师两条线。每篇笔记自足、格式统一，打开即用，库内体例为：

```
# 篇名 · 一句话定位
## README · 导览
### README_1 子板块名称
### README_2 子板块名称
## 板块0 · 学习路径和建议
### 0_1 学习路径
### 0_2 使用建议与边界声明
## 板块1 · 板块一的名称
### 1_1 板块1子板块名称
```

- 一级标题只有 1 个（篇名）；`## README · 导览` 与 `## 板块N · 名称` 同级，`### README_N` 与 `### N_M` 同级，层级不跳级。
- 板块0 承担「学什么 + 先学什么 + 怎么练 + 到哪算达标」的总控，下设 `0_1 学习路径`、`0_2 使用建议与边界声明`。
- 每篇配「案例小故事」与「自测清单」，读完能自查是否达标；图示一律用 ASCII 字符画、表格或缩进文本，不依赖任何外链图片。
- 时间以相对表述（第 1 周 / 30 天 / 3 个月）呈现，不写死年份，随当年公告更新。

## 板块0 · 学习路径和建议

### 0_1 学习路径

1. **先定级别与省份**：确认自己报一级还是二级，查本省当期报考口径、合格线、考试形式与报名平台。
2. **读对应知识库 README 与板块0**：明确全周期主线，做水平自测，确定起步点。
3. **按四段主链推进**：资格确认 → 四科备考（零基础先管理/法规打底，再经济，最后实务案例）→ 注册流程 → 执业落地。
4. **用案例与自测收口**：每篇末的「案例小故事」「自测清单」用于回验，未达标就回到对应板块重练。

### 0_2 使用建议与边界声明

- 内容仅供学习参考，**不构成报考承诺、押题或"包过"承诺**。
- 涉及资格、年限、合格线、注册等硬信息，一律以**本省当期考试公告**为准；命令、参数、政策可能随版本更新。
- 本仓库全部文件由公开或原始资料收集而来，并经 AI 工具重新归纳、整理与结构化；整体格式与大纲参考了「庚戊学堂」的学习模块组织方式，并在此基础上增补了 README 头部板块。原始资料、教材与官方文件的著作权归各自权利人所有，本仓库仅对**整理汇编成果**采用 CC BY 4.0（见文末协议）。二创请注明出处，商业使用前请自行确认合规。
