# 建筑与建造师认证考试笔记本（**`construction-certs`**）

[![License: CC BY 4.0](https://img.shields.io/badge/License-CC%20BY%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by/4.0/deed.zh)

> 把「一级 / 二级建造师」的报考、备考、注册与执业，拆成可执行动作的备考笔记库。
> 2 篇结构化笔记 · 26 个板块 · 189 个小节 · 约 10 万字 · 全中文整理。

本仓库不是教材复刻，也不是押题合集，而是一套**以"考得过、用得上"为交付目标的行动手册**：每一篇都按「资格 → 考试 → 注册 → 执业」全周期拆成若干板块，板块内再拆成「这是什么 → 为什么 → 怎么办 → 怎么验证 → 出错怎么办」，读完能照着做，而不是读完只剩一句"有道理"。

## 📖 分区说明

### 一级建造师（1 篇）

覆盖法规、管理、经济、实务四科，按「资格 → 考试 → 注册 → 执业」四段主链组织，重点处理零基础起步、科目取舍、滚动期排期与实务案例作答。

### 二级建造师（1 篇）

在四段主链之外，把**省级差异**（报考口径、合格线、考试形式、报名平台、注册范围）作为第一优先级单独处理，适合报考条件或分数线受本省政策影响较大的考生。

> 两篇均以"单文件"承载：篇首为 README 导读与阅读路径，板块0 做定位与决策，板块1~N 对应各阶段主题，篇末附案例小故事与自测清单。

## 🧭 笔记体例

每篇笔记自足、格式统一，打开即用：

```
# README · 导读与导航
# 板块0 · 定位与决策
## 0_1 小节
## 0_2 小节
# 板块1 · 报考资格与各省差异
## 1_1 ……
```

- 板块0 固定承担「全景地图 + 阅读路径 + 决策表 + 自测」；
- 每篇配「案例小故事」与「自测清单」，读完能自查是否达标；
- 图示一律用 ASCII 字符画、表格或缩进文本，不依赖任何外链图片；
- 时间以相对表述（第 1 周 / 30 天 / 3 个月）呈现，不写死年份，随当年公告更新。
